## kb-recall 知识库字段范围召回

根据当前影库查询诉求和知识库范围，召回可用于字段选择、参数构造和工具调用的字段范围提示词。

### 命令格式

```bash
kbcli kb-recall --text <查询诉求> [--scope <PATH>]...
```

### 参数

- `--text`：必填。当前影库数据查询诉求，需包含查询对象、查询意图和必要限定条件。
- `--scope`：可选。完整路径，直接从 `<catalog>` 表格第一列复制；需要多个范围时，重复传入多个 `--scope`。若首次调用未返回 `<text>`（仅返回 `<catalog>`），可放宽到品类层（如 `/影库知识库/电视剧`）或不传 `--scope` 再召一次。

路径按 `/` 划分层级，具有父子包含关系：路径越短，覆盖的知识库范围越大，并包含其下级路径的所有字段；路径越长，范围越精确。

### 两段式调用（按输出分支）

kb-recall 一次调用会返回三种互斥结果之一，按下表分支处理：

| 输出 | 含义 | 下一步动作 |
|------|------|-----------|
| `<text>...</text>` | 召回成功，返回字段范围 | 直接进入 **Step 2**：用 `<text>` 里的字段构造并执行 `kbcli kb-search`，**无需**再调 kb-recall |
| `<catalog>...</catalog>` | 仅返回目录，作用域过宽无法定位字段 | **再调一次** kb-recall：从 `<catalog>` 第一列选路径作为 `--scope`（可多个），重复直至返回 `<text>` |
| `<error>...</error>` | 参数非法或执行失败 | 修正参数后重试；不要把 `<error>` 内容当作查询结果 |

两段式流程：`kb-recall`（返回 `<catalog>` → 选路径再召一次 → 返回 `<text>`）→ 取数。**具体 `--text`、`--scope`、`--sql` 内容以每次实际返回为准，禁止照搬示例。**

### 召回成功后交给谁取数（按 `domain_knowledge` 分段）

| `<text>` 里的段 | 标识 | 取数方式 |
|---|---|---|
| **metadata 段** | `-ES-*`（如 `影库知识库-ES-0`） | **`kbcli kb-search --query 'SELECT ... WHERE ...'`**。⚠️ 若需 `range`（区间）/`rank`（排序）/`exact`（精确）/多库并行 → CLI 表达不了，改用 MCP `kb_search` |
| **metric 段** | `-MYSQL-24` | **电视剧播放**：取 md_doc 内 SQL，用 `kbcli kb-search --database <md_doc的db_name> --sql <md_doc的SQL>` 执行；**其他品类**：缺少 SQL 模板来源（原承接技能已下线），⛔ 禁止凭记忆拼 SQL，如实说明限制 |

> ⛔ 两种模式**互斥**：`--query` 与 `--database/--sql` 不可同时传；metric 段的表/SQL 禁止塞进 `--query`。

`<catalog>` 示例（路径/字段为示意，实际以每次返回为准）：

```md
| # | description |
|---|--------|
| /影库知识库 | 知识库说明 |
| /影库知识库/电视剧 | 分类说明 |
| /影库知识库/电视剧/项目信息 | 一级标签说明 |
```

`<text>` 示例（字段/domain_knowledge 为示意，实际以每次返回为准）：

```md
召回结果：提问相关的元数据字段包括如下。这些字段的定义和枚举值将作为后续 kb_search 等工具调用的参考依据。

domain_knowledge: 影库知识库

| 字段中文名 | 字段别名 | 字段简述 | 字段参数类别 | 字段枚举值 |
|---|---|---|---|---|
| 项目名称 | 片名、剧名 | 项目的中文名称 | string | - |

domain_knowledge: 全网知识库
...
```

### 示例

```bash
kbcli kb-recall --text <查询诉求>
```

```bash
kbcli kb-recall \
  --text <查询诉求> \
  --scope <从-catalog-第一列复制的路径> \
  --scope <另一个路径>
```

### 失败处理

- kb-recall 报错/超时/返回空：修正参数重试；仍不行则据已有上下文如实说明，**禁止编造字段或结果**。
- 不要在同一次需求中**一字不差重复** kb-recall 命令（说明参数未变，重试不会得到新结果）；应调整 `--text` 或 `--scope` 后再试。
